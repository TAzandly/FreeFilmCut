# Text template library (text-template)

Sibling to `text-anims/` and `sticker-anims/`, separate pack type:

- Folder: `text-templates/`
- `manifest.type` = `text-template`
- `index.json` = string array of **.vfxpack filenames** (include `.vfxpack`)

Editor: Project pack type **Text template** → Export VfxPack (or File → Export Text Template pack).

OpenCut: Assets → Text → Text templates.

Packs may include `textTemplate.stickers` + `mediaPlayers` (GIF/sequence under pack/media and pack/sequences).
